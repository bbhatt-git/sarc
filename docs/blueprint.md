# **App Name**: SARC Education Foundation

## Core Features:

- Hero Section Generation: Generate a selection of impactful headlines and sub-headlines that highlight the foundation's emphasis on excellence and character building.
- Navigation Menu: Implement a clean, intuitive navigation menu to ensure easy access to all key sections of the site.
- Staff Directory: Create a professional staff directory template with individual profile pages, highlighting qualifications and educational philosophies.
- Curriculum Details: Develop detailed curriculum pages for primary, secondary, and college levels, outlining the academic offerings.
- Admissions Landing Page: Design a high-conversion admissions landing page targeted at prospective parents, providing all necessary information and calls to action.
- News & Gallery Section: Establish a news and gallery section to showcase campus life, events, and student achievements.

## Style Guidelines:

- Primary color: Sky Blue (#87CEEB) to represent knowledge, trust, and stability.
- Background color: Light Gray (#F0F8FF) to provide a clean and modern base.
- Accent color: Soft Red (#E67777) for calls to action and important information to guide users.
- Body text font: 'Inter' sans-serif font to give a modern, clean feel. Headlines should also use 'Inter'.
- Incorporate elegant and minimalist icons related to academic disciplines and school activities.
- Modern glassmorphism with animated aesthetic, similar to https://www.thegreatsimplification.com/, logo: public/images/sarc.png
- Subtle animations to create engaging user experience such as page transitions and parallax scrolling effects.
